# 口播草案（待审）

你现在看到的这个人，会是我；你听到的声音，也会尽量保留我原来的语速和表达方式。但这条视频，我没有为它重新架机位、打光和录完整口播。

我想测试的，不是一个“输入文案就自动发布”的工具，而是一套需要我在关键节点确认的视频工作流。

第一步，用几张真实照片锁定人物特征，再生成一张稳定的十六比九场景母图。这一步最重要的不是场景有多炫，而是这个人是不是真的像我。

第二步，用干净的旧录音做一个短声音测试，再让母图说十几秒话。只有声音、嘴型和脸部稳定性通过，才会生成更长的片段。

第三步，Codex 根据完整脚本规划哪些地方保留人物，哪些地方换成字幕、信息卡、流程图或素材画面。包装尽量用可重复的程序化渲染，这样下一条视频才能继续沿用同一套风格。

最后，我会完整看一遍预览，检查错字、嘴型、黑帧、爆音和画面穿帮。所以这套流程的意义，不是完全取消人的判断，而是把重复的制作环节固定下来，让我把时间放在内容和最后的质量上。

这条样片，就是它的第一次正式测试。
