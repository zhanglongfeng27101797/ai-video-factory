# 工具使用说明

## 检查电脑环境

```bash
python3 scripts/check_env.py
```

会检查 Git、FFmpeg、Node.js、npm、uv 和 `video-use` 技能，也会告诉你两个 API Key 是否已设置。只检查“有没有”，不会显示密钥内容。

## 估算数字人成本

```bash
python3 scripts/estimate_cost.py --duration 120 --avatar-seconds 35 --engine photo
```

- `--duration`：整条视频秒数。
- `--avatar-seconds`：数字人实际出镜秒数。
- `--engine photo`：照片数字人。
- `--engine digital-twin`：数字分身。
- `--retry-reserve 0.4`：预留 40% 重试成本。
- `--usd-cny 7.1`：用于估算的美元兑人民币汇率。

这个命令不联网、不调用 API，只进行本地计算。

## 新建一条视频项目

```bash
python3 scripts/bootstrap_project.py pilot-002
```

会在 `projects/pilot-002/` 建立文案、策略、输入素材、剪辑中间件、输出和质检目录。

## 检查一条已生成的视频

```bash
python3 scripts/qa_video.py path/to/final.mp4 --output path/to/qa
```

会读取视频和音频参数，从首部、四分之一、中点、四分之三和尾部抽取审查图，并生成 `report.json` 质检报告。
