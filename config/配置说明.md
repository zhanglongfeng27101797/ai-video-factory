# 配置文件中文说明

JSON 里的英文字段名是供程序读取的固定接口，不能直接翻译。修改右边的值即可。

## `brand.example.json`：视觉品牌配置

| 英文字段 | 中文含义 |
| --- | --- |
| `name` | 这套视觉风格的名称 |
| `aspect_ratio` | 画面比例，当前为 16:9 |
| `resolution` | 画面宽度和高度 |
| `fps` | 每秒帧数 |
| `palette` | 整体配色 |
| `background` | 主背景色 |
| `surface` | 信息卡、面板表面色 |
| `text` | 主文字颜色 |
| `muted` | 次要文字颜色 |
| `accent` | 重点强调色 |
| `typography` | 字体设置 |
| `heading` / `body` | 标题字体 / 正文字体 |
| `subtitles` | 字幕设置 |
| `max_chinese_characters_per_line` | 单行最多中文字数 |
| `max_lines` | 最多行数 |
| `placement` | 字幕位置 |
| `highlight_keywords` | 是否强调关键词 |
| `motion` | 动效设置 |
| `tone` | 整体动效气质 |
| `one_new_information_event_at_a_time` | 是否一次只揭示一条新信息 |
| `minimum_card_hold_seconds` | 信息卡最短停留秒数 |

## `project.example.json`：单条视频配置

| 英文字段 | 中文含义 |
| --- | --- |
| `title` | 项目名称 |
| `target_duration_seconds` | 成片目标时长（秒） |
| `avatar_target_seconds` | 数字人预计出镜时长 |
| `avatar_engine` | 数字人类型：`photo` 或 `digital-twin` |
| `voice_mode` | 声音生成模式 |
| `delivery` | 输出规格 |
| `width` / `height` / `fps` | 宽度 / 高度 / 帧率 |
| `approval_gates` | 制作过程中必须通过的确认点 |

建议复制示例文件为 `brand.json` 或项目自己的 `brief.json`，再修改；保留 `*.example.json` 作为原始模板。
