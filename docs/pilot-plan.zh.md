# 两分钟样片：需求和不确定性门槛

## 完成标准

样片必须在 105–135 秒内讲清一个完整主题，正常速度播放时画面有明确的设计意图，且不得出现明显的人物变脸、嘴型错位、字幕错误、黑帧、爆音或无法读取的信息卡。

输出规格：1920×1080、30 帧/秒、H.264 视频、AAC 音频、16:9。

## Codex 可以自主决定的内容

- 将已确认文案整理成开场钩子、问题、解释、例子和结尾。
- 提出节奏、数字人/B-roll 比例、信息卡位置、字幕分块、转场和音乐克制程度。
- 生成可重现的信息卡、图示、字幕、转场、剪辑决策、渲染结果和质检证据。
- 后续项目直接复用已确认的品牌和人物素材。

## 必须由用户判断的内容

- 生成的人是否仍然像本人。
- 克隆声音是否不仅音色相似，表达方式也像本人。
- 工作室场景是否符合想对外展示的形象。
- 文案的说法和语气是否可以使用本人身份发布。
- 最终预览是否通过。

## 门槛一：人物身份与场景母图

输入：建议提供 3–5 张近期、无滤镜照片，其中至少一张清晰正脸，可再提供四分之三侧脸和自然表情。只有风格一致时，10–20 张照片才有帮助。AI 生成的人物变体不得与真实照片同等对待，否则误差会叠加。

处理：以真实照片锁定身份，生成 2–4 张 16:9 工作室候选图，再选定唯一的人物场景母图。其他生成图只是风格候选，不是身份训练数据。

验收项：

- 无需解释就能认出本人。
- 眼距、脸型、发际线、牙齿、手部和饰品稳定。
- 坐姿自然，桌面和物体几何关系合理。
- 留有放置信息卡和字幕的空间。
- 背景不包含预先生成的文字。

主要不确定性：人物偏离和塑料感皮肤。在购买长时间数字人生成前必须解决。

## 门槛二：声音与嘴型

输入：一段已确认的 45–60 个中文字测试文案，以及干净的本人声音样本。

输出：10–15 秒低成本预览。

验收项：

- 第一遍听就感觉像本人。
- 辅音、停顿和句尾自然。
- 不出现明显嘴型延迟、牙齿冻结、脸部闪烁或不自然的眨眼循环。
- 响度稳定，没有削波失真。

主要不确定性：好看的静态母图不一定适合张嘴说话。如果测试失败，必须先更换母图或数字人模式。

## 门槛三：内容与视觉方案

Codex 剪辑前提交一份通俗易懂的方案：叙事节点、预计时长、数字人出现区间、B-roll 需求、信息卡、字幕样式、配色和付费生成成本。

默认两分钟结构：

- 0–8 秒：数字人开场钩子。
- 8–30 秒：提出问题，数字人配合一张信息卡。
- 30–75 秒：使用图示、截图和 B-roll 解释，数字人只在必要时出现。
- 75–105 秒：例子或证据。
- 105–120 秒：数字人结论和行动建议。

主要不确定性：编辑审美。通过确认视觉方案解决，不要用反复渲染整条视频的方式试错。

## 门槛四：720p 预览

完整审查故事、节奏、信息卡可读性、字幕错字、数字人连续性和音乐音量。修改意见记录在 `projects/<项目名>/edit/project.md`。

## 门槛五：最终成片

只在预览通过后渲染 1080p。输出最终视频和质检报告，报告包含时长/编解码检查和抽样审查帧。

## 成本控制规则

执行时必须使用当时官方公布的 Avatar IV/V API 价格。仓库内的估算器默认使用 Photo Avatar 0.05 美元/秒、Digital Twin 0.0667 美元/秒。这只是预算，不是账单报价。预算必须包含一次短测试和 30%–50% 的重试余量。
